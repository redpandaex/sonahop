# Windows ↔ Android 首版音频

目标沿用已确认范围：两台 Android 同时收听 Windows 系统声音；麦克风模式只接纳一台 Android，并暂停全部收听。完整双工、独立驱动、USB 音频与其他系统留待后续。

电脑使用 Windows 进程级系统声音捕获，排除 SonaHop 自身，手机增益不改系统扬声器音量。手机 AudioTrack 播放、AudioRecord 录音和 foreground service 生命周期由 Android 原生适配层负责，编码/解码和会话调度使用共享 Rust。麦克风输出必须由用户指定已经安装的虚拟音频 render 端点，不自动使用物理扬声器。

连接采用发现、输入电脑六位连接码、SPAKE2 密钥协商、电脑明确批准；通过批准后才允许加密控制和音频。Opus 固定 48 kHz / 20 ms，收听 stereo 96 kbps，麦克风 mono 48 kbps。连接媒体队列最多三帧，写入超时断开而不积压延迟。应用显示真实连接、等待批准、实际播放/录音与错误。

停止、切换模式、网络断开、权限撤销、音频焦点丢失和通知停止都释放音频；麦克风不能自动重新开启。保留真实端点枚举、诊断 WAV CLI、外观和用户偏好。

用户本轮授权完成上述功能，明早亲自测试；不运行自动测试、浏览器/设备测试、音频录制/播放及长验证构建。源码状态、构建结果和真机结果分别记录。旧协议 v1 LAN 文档仅为历史步骤，本文件以 v2 为准。
